# 분석 진입 카드 색상·링크 개선 설계

## 목표

`/users`의 지원 프로필 카드가 공통 레이팅 색상 체계를 따르게 하고, 홈의 유저 분석·대회 분석 기능 카드에서 각 분석 인덱스 페이지로 이동할 수 있게 한다.

## 원인과 범위

지원 프로필 카드의 `SPECIALIST` 문구와 아이콘은 현재 파란색 Tailwind 클래스를 직접 사용한다. 레이팅 도메인과 공통 `RatingTitleText`에는 1429 레이팅의 `SPECIALIST` 색상이 이미 민트 계열인 `text-teal-700 dark:text-teal-400`으로 정의돼 있으므로, 카드가 공통 색상 primitive를 우회한 것이 색상 불일치의 원인이다.

변경 범위는 다음 두 화면에 한정한다.

- `/users`의 지원 프로필 카드
- `/`의 유저 분석·대회 분석 기능 카드

상단 상세 데모 링크와 기존 상세 분석 페이지는 변경하지 않는다.

## 지원 프로필 카드

지원 프로필의 현재 레이팅을 색상과 칭호의 단일 기준으로 사용한다.

- `getRatingBand(user.currentRating)`으로 레이팅 밴드를 계산한다.
- 표시 칭호는 계산된 밴드의 `title`을 사용해 카탈로그의 중복된 `title` 필드를 제거한다.
- 칭호는 공통 `RatingTitleText`를 사용해 `SPECIALIST`에 `text-teal-700 dark:text-teal-400`을 적용한다.
- 유저 아이콘에는 같은 레이팅 제목의 공통 색상 클래스를 적용한다.
- 카드 왼쪽 강조선에는 밴드의 정확한 색상 `rgb(20, 184, 166)`을 적용한다.

이 구조는 이후 다른 유저를 추가하더라도 현재 레이팅만 바꾸면 칭호와 색상이 함께 변경되게 한다.

## 홈 기능 카드 링크

홈의 두 기능 카드는 카드 전체가 하나의 명확한 링크로 동작한다.

- 유저 분석 카드: `/users`
- 대회 분석 카드: `/contests`

각 링크에는 기능명과 구분되는 접근 가능한 이름을 제공한다. 카드에는 hover 시 테두리·그림자 변화와 키보드 `focus-visible` 링을 적용하며, 다크 모드에서도 링 대비를 유지한다. 기존 상단의 `유저 분석 데모 보기`와 `대회 분석 데모 보기`는 각각 상세 데모 경로를 계속 가리킨다.

## 컴포넌트 경계

- `SupportedUserCard`는 현재 레이팅에서 밴드를 계산하고 공통 레이팅 표현을 조합한다.
- `userCatalog`는 사용자 식별자, 상세 링크, 현재 레이팅, 해결 수만 보유한다.
- 홈 페이지는 두 기능 카드의 인덱스 링크를 직접 선언한다. 별도 데이터 계층이나 범용 카드 abstraction은 추가하지 않는다.

## 접근성

- 민트 텍스트는 프로젝트의 대비 보정 클래스인 `text-teal-700 dark:text-teal-400`을 사용한다.
- 정확한 canonical 민트색은 텍스트가 아니라 두꺼운 강조선에도 사용해 시각적 정체성을 보강한다.
- 홈 기능 카드 링크는 카드 전체에 명확한 focus 링을 표시한다.
- 아이콘은 장식용으로 유지해 `aria-hidden="true"`를 사용한다.

## 테스트와 검증

- `/users` 페이지 테스트는 `SPECIALIST`가 teal 클래스를 사용하고 파란 클래스를 사용하지 않는지 확인한다.
- 지원 카드 테스트는 아이콘의 teal 클래스와 카드 강조선의 canonical 민트색을 확인한다.
- 홈 테스트는 두 기능 카드 링크가 각각 `/users`, `/contests`를 가리키는지 확인한다.
- 상단 상세 데모 링크가 기존 상세 경로를 유지하는지 회귀 검증한다.
- 구현 후 focused 테스트, 전체 `npm test`, lint, `next typegen`, `tsc --noEmit`, 프로덕션 build를 실행한다.

## 비목표

- 레이팅 밴드 정의 변경
- 상세 유저 프로필 카드의 색상 정책 변경
- 새로운 유저·대회 데이터 추가
- 홈 상단 상세 데모 링크 변경
