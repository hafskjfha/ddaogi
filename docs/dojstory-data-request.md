# DOJstory 위키에 필요한 정보와 데이터 수집 체크리스트

작성일: 2026-10-21 KST  
최종 수정일: 2026-10-22 KST  
관련 문서: [DOJstory 위키 설계 초안](./dojstory-design.md), [구현 계획](./dojstory-implementation-plan.md), [사용자 정정·보완](./dojstory-data/clarifications.md)

## 현재 확보 상태와 추가 수집 범위

원문 6개와 사용자 보완 자료를 확보했다. 아래의 기능별 목록·진행표는 전체 수집을 위한 서식이며, 미수집 표기를 이미 제공한 자료가 없다는 뜻으로 사용하지 않는다. 현재 수록 범위와 실제 추가 요청은 구현 계획을 기준으로 확인한다.

연구의 정식 이름·모든 선행 연구 필수 조건·DOJpower 또는 가치의 증표 조건, 오로라 합성 효과, `x`의 효과 없음, 연구 키트 소비, 스타포스 조건부 하락률, 광산 게이지와 XP의 동일 단위는 사용자 보완으로 확인되었다. 이 항목은 다시 요청하지 않는다. AI 여부는 배경에만 표시하므로 비배경 장비의 AI 여부는 수집하지 않는다.

추가 수집 우선순위는 실제 조합법의 투입·산출·시간·조건, 광산 레벨 2 등 누락 수치, DOJpower 정확한 산식, 장비 획득처와 미확보 이미지다. 이미지는 추후 보완하며 구현을 막지 않는다.

현재 접근할 수 있는 자료부터 모으면 된다. DOJpower가 부족해 확인할 수 없는 연구·조합법·공장은 미확인으로 남겨도 된다. 전체 자료를 확보할 때까지 기다리지 않고, 실제로 보이는 사례를 바탕으로 위키를 구성한다.

가상의 아이템·수치로 빈칸을 채우지 않는다. 게임에서 확인한 이름과 원문을 그대로 주면 데이터 구조화는 구현 과정에서 처리한다.

## 먼저 가져오면 되는 자료

아래 순서로 가능한 만큼 수집한다. 스크린샷, 복사한 텍스트, 표, 실제 제공된 JSON 중 편한 형식이면 된다. JSON 작성이나 파일명 정리는 필수가 아니다.

- [ ] DOJstory 전체 메뉴와 시작 화면
- [ ] DLC 문제팩과 DOJpower 설명 또는 관련 도움말
- [ ] 현재 DOJpower와 화면에 표시되는 산정 대상 문제 목록·난이도·점수
- [ ] 현재 볼 수 있는 연구 목록과 잠긴 연구의 표시 내용
- [ ] 열람 가능한 연구 하나의 상세와 그 연구가 해금하는 대상
- [ ] 실제 조합법 하나의 투입 재료·수량과 결과물·수량
- [ ] 공장 하나의 설명과 채굴 또는 생산 화면
- [ ] 위 사례에 등장하는 아이템의 상세 정보
- [ ] 장비 하나의 상세와 확인 가능한 강화 정보

가능하면 연구 → 조합법 → 재료 → 공장 중 실제로 연결되는 사례를 모은다. 연결 사례가 없으면 각각 독립된 사례도 충분하다. 같은 대상을 여러 화면에서 확인했다면 이름을 함께 남겨 연결할 수 있게 한다.

## 자료마다 같이 남기면 좋은 정보

| 정보 | 기록 방법 |
| --- | --- |
| 확인일 | 날짜, 가능하면 시간과 시간대 |
| 화면 위치 | 어떤 메뉴에서 열었는지, 주소가 있으면 주소 |
| 게임 버전 | 표시되어 있을 때만 기록, 없으면 미확인 |
| 현재 상태 | 개인 DOJpower, 선행 연구·공장 레벨 등 표시값에 영향을 줄 수 있는 상태 |
| 원문과 단위 | 아이템명, 수량, 초·분·시간, 회당·분당 등 표시 그대로 |
| 잠긴 부분 | 읽을 수 있는 이름·조건과 보이지 않는 항목을 구분 |

전체 화면 한 장과 글자가 잘 보이는 상세 화면이 있으면 좋다. 캡처에 없는 값은 기억으로 보충하지 말고 미확인으로 남긴다.

## DLC와 DOJpower

알려진 내용은 DLC 문제 풀이와 상위 15개 난이도가 DOJpower 산정에 연결되고, 높은 DOJpower가 더 많은 연구 해금에 필요하다는 것이다. 다음은 정확한 규칙을 확인하기 위한 목록이며 답을 가정하지 않는다.

- [ ] DLC가 하나의 문제팩인지 여러 팩을 묶는 메뉴인지
- [ ] DOJpower 대상에 포함되는 문제와 제외되는 문제
- [ ] 문제를 풀었다고 인정하는 조건과 부분 점수 처리
- [ ] 상위 15개를 고르는 기준이 표시된 원문
- [ ] 난이도를 DOJpower에 반영하는 정확한 산식·표·설명
- [ ] 대상 문제를 15개 미만으로 해결했을 때의 처리
- [ ] 같은 문제의 재제출·중복 수록 처리
- [ ] 문제 난이도가 바뀌었을 때 반영 방식
- [ ] 현재 DOJpower와 실제로 반영된 문제 목록을 함께 보여주는 화면
- [ ] 풀이 전후 DOJpower 변화가 있는 자료 — 확보 가능한 경우만

산식 원문이 없으면 현재 값과 화면만 먼저 받는다. 몇 개의 관찰 사례에 맞는 공식을 만들어 확정하지 않는다.

## 연구

- [ ] 실제 이름과 설명
- [ ] 요구 DOJpower와 비교 조건이 표시된 원문
- [ ] 선행 연구 또는 다른 요구 조건
- [ ] 비용 재화·재료와 각각의 수량
- [ ] 소요 시간 또는 즉시 완료 여부
- [ ] 해금되는 조합법·공장·기능의 정확한 이름
- [ ] 다른 수치나 생산 규칙을 바꾸는 효과가 있으면 원문
- [ ] 단계·레벨이 실제로 있다면 단계별 차이
- [ ] 연구 전·진행 중·완료 후 차이 — 실제 존재하고 확인 가능한 상태만
- [ ] 복수 연구 동시 진행·취소·반환 규칙 — 설명이 보이는 경우

DOJpower 요구치와 연구에 소비되는 비용은 따로 기록한다. 선행 연구는 모두 필수이고, 요구 DOJpower 이상 또는 가치의 증표 착용 조건도 충족해야 한다. 이 결합 방식은 이미 확인되었으므로 새 연구에서는 대상 이름과 구체적인 요구치·비용만 추가 수집하면 된다.

### 잠긴 연구는 여기까지만 수집해도 됨

- [ ] 이름이나 아이콘이 보이는지
- [ ] 요구 DOJpower가 보이는지
- [ ] 선행 조건이나 해금 효과가 일부라도 보이는지
- [ ] 전체 상세가 숨겨졌는지, 일부만 숨겨졌는지

이름만 보이면 이름만 기록한다. 보이지 않는 연구의 이름·효과·수치는 만들지 않는다. 이후 DOJpower가 오르거나 다른 실제 자료를 확보하면 이어서 보완한다.

## 조합법

- [ ] 조합법 이름 또는 결과물 이름
- [ ] 투입 아이템의 정확한 이름과 각각의 수량
- [ ] 결과 아이템의 이름과 산출 수량, 복수 결과물이 있으면 전부
- [ ] 해금 연구와 다른 실행 조건
- [ ] 조합을 실행하는 메뉴·장소·공장
- [ ] 1회 소요 시간과 추가 비용
- [ ] 성공 확률·부산물·재료 반환 등 실제 표시된 규칙
- [ ] 같은 결과물을 만드는 다른 조합법이 보이면 해당 정보

해금 연구의 이름만 확인되고 상세가 잠겨 있어도 이름과 출처를 남긴다. 수량이 1회 기준인지 일괄 제작 기준인지 화면에서 구분할 수 있으면 함께 기록한다.

## 공장과 채굴 및 생산

- [ ] 공장 이름과 역할 설명
- [ ] 건설·해금 조건과 필요한 연구
- [ ] 건설에 필요한 재화·아이템과 수량
- [ ] 채굴 대상 또는 생산 결과물
- [ ] 작업에 투입되는 아이템·연료·기타 비용 — 실제 존재하는 경우
- [ ] 1회 투입량·산출량과 작업 시간
- [ ] 채굴량·생산량이 표시되는 정확한 단위
- [ ] 작업 선택 또는 조합법 선택 화면
- [ ] 레벨·업그레이드가 있다면 비용과 효과
- [ ] 설치 수·동시 작업 수·저장량 제한 — 표시가 있는 경우
- [ ] 반복 생산, 자동 수령, 오프라인 진행, 생산 중단 조건 — 설명이 있는 경우
- [ ] 연구나 개인 상태로 생산량·시간이 달라지는지

채굴 공장과 생산 공장이 별도라면 가능한 범위에서 각각 하나씩 받으면 좋다. 화면에 표시된 값이 기본값인지 현재 계정의 효과가 적용된 값인지 알 수 없으면 그대로 미확인으로 적는다.

## 아이템과 장비 및 강화

### 아이템 공통

- [ ] 이름, 설명, 아이콘 또는 이미지
- [ ] 게임에서 사용하는 실제 분류와 등급
- [ ] 획득 방법과 관련 조건
- [ ] 사용처가 표시되어 있으면 해당 내용
- [ ] 내부 ID가 자료에 제공되면 해당 ID

### 장비와 강화

- [ ] 장비 분류·부위와 기본 능력치
- [ ] 착용 조건·장비 효과가 있으면 원문
- [ ] 현재 강화 단계와 가능한 단계 범위
- [ ] 단계별 비용·재료·효과
- [ ] 성공 확률과 실패 결과
- [ ] 장비별 예외, 보장·보호 등 실제 안내된 규칙

획득 확률이 공개되지 않았으면 미확인으로 둔다. 메이플스토리와 비슷하다는 설명을 근거로 강화 파괴·하락·천장 규칙을 추가하지 않는다.

## 문제 풀이 보상

- [ ] 보상이 지급되는 풀이 조건
- [ ] 최초 해결·재제출·부분 점수에 따른 차이
- [ ] 보상 아이템·재화·수량을 보여주는 화면
- [ ] 난이도나 DLC 문제팩에 따른 차이가 있는지
- [ ] 수령 방식, 일일 제한, 중복 보상 조건이 표시되면 원문

보상을 관찰한 사례와 항상 적용되는 규칙을 구분한다. 한 번 받은 아이템을 모든 문제의 고정 보상으로 일반화하지 않는다.

## 복사해서 사용할 수집 양식

아래 양식은 실제 대상을 기록하기 위한 빈 서식이다. 이름이나 수치가 없는 항목은 미확인으로 남기면 된다. 캡처와 원문만 제공해도 되므로 모두 작성할 필요는 없다.

```text
대상 종류:
실제 이름:
확인일과 시간대:
메뉴 위치 또는 주소:
기준 게임 버전 또는 미확인:
자료 파일명 또는 원문 위치:

화면에 표시된 설명 원문:

조건과 선행 대상:
요구 DOJpower:
비용과 소비 재료:
투입량과 산출량:
시간과 단위:
효과 또는 해금 대상:
획득 방법과 사용처:

표시값에 영향을 줄 수 있는 현재 계정 상태:
잠겨서 확인할 수 없는 항목:
출처마다 값이 다른 항목:
추가 메모:
```
